# Library Management API

A Library Management REST API built using ASP.NET Core Web API and Dapper.

## Technologies Used

- ASP.NET Core Web API
- C#
- Dapper
- SQL Server
- Stored Procedures
- Repository Pattern
- Dependency Injection
- Swagger

## Features

- Book Management
  - Add Book
  - Get All Books
  - Get Book By Id
  - Update Book
  - Delete Book
  - Search Books

- Member Management
  - Add Member
  - Get All Members
  - Get Member By Id
  - Update Member
  - Delete Member
  - Get Member Details

- Borrowing Management
  - Borrow Book
  - Return Book
  - Get All Borrowings
  - Get Member Borrowing History
